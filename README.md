### About

I build applications end to end: system modeling (UML, ERD, flowcharts), then the frontend, the backend, and the database, for web and mobile. I also like turning raw data into dashboards that answer real questions.

Right now I'm a **Full Stack Developer (contract) at PT Sistem Pelayanan Kesehatan dan Data (SPKD)**, working on hospital credentialing and hospital information systems. Digital Business graduate from ULBI Bandung, open to work and collaboration.
